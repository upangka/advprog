# 认知升级-思维转变

从解方程走向**理解数据流动**的认知升级，从“代数计算”到“几何直观” 的思维转变

| 以前的视角（解方程） | 现在的视角（线性变换）                   |
| -------------------- | ---------------------------------------- |
| $Ax = b$: 求 $x$     | $Ax = b$: 向量 $x$ 被矩阵 $A$ 映射到 $b$ |
| 矩阵是系数表         | 矩阵是“映射规则”                         |
| 你是在“解谜”         | 你是在“观察数据如何流动”                 |

---

[Week 2](../Week2-Solving-systems-of-linear-equations/README.md)的视角——`矩阵 = 方程组的系数`,学的是：

$$
Ax = b
$$

这个公式被你理解为：
“**已知系数矩阵 $A$ 和常数项 $b$，求未知数 $x$。**”

- 把方程组写成增广矩阵
- 做行化简 → 行阶梯形
- 回代求解

这时候，**矩阵 $A$ 只是一堆数字的表格**，任务是“破解”它，找出隐藏的 $x$。

**关键词：解方程、求未知数、代数计算。**

---

现在换了一个角度看 $Ax = b$:

“**把向量 $x$ 输入到矩阵 $A$ 这个‘机器’里，输出一个新的向量 $b$。**”

想象一下：

```txt
[ 向量 x ]  →  [  矩阵 A  ]  →  [ 新的向量 b ]
              (线性变换机器)
```

矩阵不再是一堆静态的数字，而是一个**能把向量“变”成另一个向量的操作**。

> 具体例子

$$
A =
\begin{bmatrix}
3 & 1 \\
1 & 2
\end{bmatrix}, \quad x =
\begin{bmatrix}
1 \\
1
\end{bmatrix}
$$

矩阵乘法：

$$
Ax =
\begin{bmatrix}
3 & 1 \\
1 & 2
\end{bmatrix}
\begin{bmatrix}
1 \\
1
\end{bmatrix} =
\begin{bmatrix}
4 \\
3
\end{bmatrix}
$$

> 几何含义：

矩阵 $A$ 把向量 $(1, 1)$ “映射”到了 $(4, 3)$。

你可以在坐标系里画出来：

- 原来从原点指向 $(1, 1)$ 的箭头
- 经过矩阵变换后，指向了 $(4, 3)$

**关键词：映射、变换、从输入到输出**。

# 线性变换

变换（Transformation） 就是“把一个东西变成另一个东西”的过程。在数学中，变换通常指把一个向量变成另一个向量：

```txt
输入向量 v  →  [  某个规则  ]  →  输出向量 w
```

**任何能把输入向量映射到输出向量的规则，都叫变换**。

一个变换要被称为**线性变换**，必须满足两条规则：

| 规则       | 数学表达                      | 大白话                            |
| ---------- | ----------------------------- | --------------------------------- |
| **加法性** | $T(u + v) = T(u) + T(v)$      | 先加后变 = 先变后加，结果一样     |
| **齐次性** | $T(k \cdot v) = k \cdot T(v)$ | 先缩放后变 = 先变后缩放，结果一样 |

线性变换 = 保持“加法和数乘”不变的变换。

换句话说：线性变换不会把直线变成曲线，不会把原点移走，不会破坏向量的线性组合关系。
