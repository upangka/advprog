# 思维转变

从解方程走向**理解数据流动**，从“代数计算”到“几何直观” 的思维跳跃

[Week 2](../Week2-Solving-systems-of-linear-equations/README.md)的视角——`矩阵 = 方程组的系数`,学的是：

$$
Ax = b
$$

这个公式被你理解为：
“**已知系数矩阵 $A$ 和常数项 $b$，求未知数 $x$。**”

- 把方程组写成增广矩阵
- 做行化简 → 行阶梯形
- 回代求解

这时候，**矩阵 $A$ 只是一堆数字的表格**，任务是“破解”它，找出隐藏的 $x$。

**关键词：解方程、求未知数、代数计算。**
