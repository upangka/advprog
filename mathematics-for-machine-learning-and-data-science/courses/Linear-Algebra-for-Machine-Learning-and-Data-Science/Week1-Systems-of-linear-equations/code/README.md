# Lab 2 Linear systems as matrices

[Lab_2_linear_systems_as_matrices.ipynb](./Lab_2_linear_systems_as_matrices.ipynb)

🎯 实验核心目标

| 目标                   | 说明                                                 |
| :--------------------- | :--------------------------------------------------- |
| **矩阵表示线性方程组** | 将系数矩阵 \(A\) 和常数向量 \(b\) 分离，构建增广矩阵 |
| **求解线性方程组**     | 使用 `np.linalg.solve(A, b)` 求解 \(Ax = b\)         |
| **判断矩阵奇异性**     | 使用 `np.linalg.det(A)` 计算行列式，判断是否有唯一解 |
| **可视化 2x2 系统**    | 用 `plot_lines()` 画出两条直线，观察交点情况         |

---

🧠 核心理论总结

| 行列式 \(det(A)\) | 矩阵奇异性         | \(Ax = b\) 的解的情况    | 几何意义（两条直线）         |
| :---------------: | :----------------- | :----------------------- | :--------------------------- |
|        ≠0         | **非奇异（可逆）** | **唯一解**               | 两条直线**相交于一点**       |
|      \(= 0\)      | **奇异（不可逆）** | **无解** 或 **无穷多解** | 两条直线**平行** 或 **重合** |

> **关键点**：行列式只能判断“有没有唯一解”。如果是奇异（`det = 0`），还需要检查常数项 \(b\) 才能区分是“无解”还是“无穷解”。

📝 本实验用到的 NumPy API

| 名称                    | 说明                                            |
| :---------------------- | :---------------------------------------------- |
| `np.linalg.solve(A, b)` | 解线性方程组 \(Ax = b\)，返回解向量 \(x\)       |
| `np.linalg.det(A)`      | 计算方阵 \(A\) 的行列式                         |
| `np.hstack((A, b))`     | 水平堆叠数组（列方向拼接），构建增广矩阵        |
| `np.reshape((2, 1))`    | 改变数组形状，将 `(2,)` 变成 `(2, 1)`，用于堆叠 |
| `np.dtype(float)`       | 指定数组元素类型为浮点数                        |
| `ndarray.shape`         | 返回数组的形状，如 `(2, 2)` 或 `(2,)`           |
| `ndarray.flatten()`     | 将多维数组展平为一维数组                        |

---

🔍 三种情况的实验对比

| 系统     | 矩阵 \(A\)           | 行列式          | 解的情况               | 图形表现         |
| :------- | :------------------- | :-------------- | :--------------------- | :--------------- |
| 系统 (1) | `[[-1, 3], [3, 2]]`  | \(-11\)（非零） | **唯一解** \((-1, 2)\) | 两条直线**相交** |
| 系统 (2) | `[[-1, 3], [3, -9]]` | \(0\)           | **无解**               | 两条直线**平行** |
| 系统 (3) | `[[-1, 3], [3, -9]]` | \(0\)           | **无穷多解**           | 两条直线**重合** |

---

📌 易错点提醒

| 易错点                                          | 正确做法                                                                              |
| :---------------------------------------------- | :------------------------------------------------------------------------------------ |
| `b` 用一维数组 `[7, 1]` 还是二维 `[[7], [1]]`？ | `np.linalg.solve()` 接受一维 `b`，代码更简洁；堆叠时才需要 `reshape`                  |
| `np.hstack()` 堆叠维度不匹配                    | `b` 是 `(2,)`，需要先 `b.reshape((2, 1))` 变成 `(2, 1)` 才能和 `(2, 2)` 的 \(A\) 堆叠 |
| 行列式为 0 时 `np.linalg.solve()` 报错          | 用 `try-except` 捕获 `LinAlgError`，避免程序崩溃                                      |
