# 双向

每个时间步的输出，是正向和反向隐藏状态的组合（例如`拼接`或`求和`）。

![alt text](./images/RNN_双向.png)

# 多层+双向

1. 同一层内：正向和反向是两条独立的链，可以各自顺序算完，然后按时间步拼接。

2. 层与层之间：必须等上一层所有时间步的正反向都算完并拼接好，才能开始下一层。

![](./images/RNN_多层_双向.png)
