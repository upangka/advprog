# Introduction to Machine Learning

> "It's the science of getting computers to learn **without being explicitly programmed**."

这句话是 Arthur Samuel（1959）那个定义的通俗版。**without being explicitly programmed** 是关键词——你不再写 `if (email.contains("million dollars")) return SPAM`，而是给模型一堆邮件和标签，让它自己学。

传统编程是「人写规则」，ML 是「机器从数据里学规则」

这个功能，如果用传统的 if-else 写，写不出来；但用 ML，能写出来。

| 应用                                 | 输入 $x$      | 输出 $y$           | 任务类型           |
| ------------------------------------ | ------------- | ------------------ | ------------------ |
| Google / Bing / Baidu 搜索排序       | 网页 + 查询词 | 排序               | 监督学习（排序）   |
| Instagram / Snapchat 人脸识别        | 图片          | 好友标签           | 监督学习（分类）   |
| 视频流媒体推荐                       | 观看历史      | 推荐电影           | 推荐系统           |
| 语音转文字 / Siri / Google Assistant | 语音          | 文字 / 动作        | 监督学习（序列）   |
| 垃圾邮件过滤                         | 邮件          | spam / not spam    | 监督学习（二分类） |
| 风力发电优化、医疗诊断、工厂质检     | 传感器 / 图像 | 功率 / 诊断 / 缺陷 | 监督学习           |

**注意：** 这里只出现了监督学习和推荐系统，还没出现无监督学习和强化学习。下一集才会展开。

## 关于网页搜索排序

搜索排序是**监督学习最成功的工业应用之一**，而且它展示了监督学习的一个关键点：

> 监督学习的"标签"不一定非得是人工标注的，也可以从用户行为里"免费"获得。

用户点击了某个搜索结果 → 隐含"这个结果相关" → 变成训练标签。这叫 implicit feedback（隐式反馈），是工业界拿标签的常用手段。这也是为什么 Google/Bing/Baidu 能积累海量训练数据——**用户每天搜索本身就在免费生产标签。**

---

> **疑问：为什么是监督学习？**

监督学习的定义就一条：**训练数据里有没有"正确答案" $y$。**

搜索排序的训练数据长这样：

| 查询词 $q$         | 网页 $d$ | 标签 $y$（相关性） |
| ------------------ | -------- | ------------------ |
| "sushi roll"       | 网页 A   | 高度相关（3）      |
| "sushi roll"       | 网页 B   | 相关（2）          |
| "sushi roll"       | 网页 C   | 不相关（0）        |
| "machine learning" | 网页 D   | 高度相关（3）      |
| …                  | …        | …                  |

这个 $y$ 就是"正确答案"——由**人工标注员**（raters）打分，或者从**用户点击日志**里反推（用户点了 = 相关）。有了 $y$，就是监督学习。

**现代搜索引擎的真实架构（简化）**

```txt
用户查询 "sushi roll"
        ↓
┌─────────────────────────┐
│ 1. 召回 (Retrieval)      │  ← 倒排索引 + BM25 + 向量检索
│    从十亿网页里筛出       │     把候选从 10^9 降到 10^3
│    几千个候选             │
└─────────────────────────┘
        ↓
┌─────────────────────────┐
│ 2. 粗排 (Pre-ranking)    │  ← 轻量模型，快速打分
│    几千 → 几百            │
└─────────────────────────┘
        ↓
┌─────────────────────────┐
│ 3. 精排 (Ranking)        │  ← Learning to Rank (监督学习)
│    几百 → 几十            │     特征：BM25、PageRank、
│                          │     点击率、查询-文档相似度...
└─────────────────────────┘
        ↓
┌─────────────────────────┐
│ 4. 重排 (Re-ranking)     │  ← 多样性、去重、业务规则
│    最终返回给用户          │
└─────────────────────────┘
```

> "Google 的搜索技术演进"

- 1998~2005 左右：PageRank 是核心排序信号，确实是马尔可夫链平稳分布。
- 2005 之后：Google 引入越来越多的 ML 信号（点击数据、查询理解、个性化），PageRank 权重逐渐下降。
- 现在：排序主体是 Learning to Rank（监督学习），PageRank 只是特征之一。2016 年 Google 还申请了 PageRank 的替代专利，叫 **RankBrain**，是一个深度学习模型。
