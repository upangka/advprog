name: picture-to-markdown
description: 将图片中的数学公式和文字转换为 Markdown 格式，使用 $...$ 行内公式，兼容 GitHub。
---

## 触发条件

用户发送图片并要求转换为 Markdown，或说“图片转markdown”、“识别公式”等类似指令。

## 输出规范

1. **公式格式**：统一使用 `$...$` 行内公式（GitHub 兼容，不依赖渲染器）。
2. **结构**：保留原图片中的条目结构（如列表项、编号、分段等）。
3. **中文解释**：完整保留原图中的中文说明文字。
4. **不额外渲染**：直接输出 Markdown 源码，不包裹代码块，不加额外说明（除非用户要求）。
5. **复杂公式处理**：
   - 分式：`\frac{分子}{分母}`
   - 上下标：`^` 和 `_`
   - 三角函数：`\sin`, `\cos`, `\tan`, `\log`, `\ln` 等
   - 根式：`\sqrt{}`
   - 希腊字母：`\alpha`, `\beta`, `\gamma` 等

## 输出模板

```markdown
- $公式$: 中文解释

- $公式$: 中文解释

- $公式$: 中文解释
```

## 示例

输入图片内容：

```
- a² + b² = 10: 变量自乘，破坏了线性。
- sin(a) + b⁵ = 15: 变量在三角函数或高次幂里。
```

输出：

```
- $a^2 + b^2 = 10$: 变量自乘（幂次不是1），破坏了线性。

- $\sin(a) + b^5 = 15$: 变量在三角函数或高次幂里，破坏了线性。
```

## 注意事项

- 如果图片中的公式无法识别，标注 `[公式识别不清]` 并保留原文。
- 如果图片包含表格或代码，按实际内容调整 Markdown 结构。
- 如果用户指定其他格式（如 `$$...$$` 或 `\[...\]`），按用户要求调整。
