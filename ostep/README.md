操作系统是“规划师”，负责制定规则和任务清单（比如：哪个程序该运行、哪个文件该读）；
CPU是“传令兵”和“计算器”，负责把规划师的任务算成具体的地址（门牌号），并通过总线把“启动命令”发送给对应的硬件控制器；
硬件控制器（硬盘/网卡/显卡）是“专业包工头”，收到CPU的启动命令后，带领自己的机械/电路团队，独立完成数据搬运的体力活，干完后通过“中断”敲一下CPU的门，告诉它“活干完了”。
