数字逻辑设计的两个核心分支

| 分支                                | 特点                                          | 典型电路                                    | 关键概念                          |
| :---------------------------------- | :-------------------------------------------- | :------------------------------------------ | :-------------------------------- |
| **组合逻辑（Combinational Logic）** | 输出**仅取决于当前输入**，无记忆功能          | 与门、或门、多路复用器、解码器、加法器、ALU | 真值表、布尔代数、卡诺图          |

# Nand门

芯片设计领域有一条著名的公理：“Anything can be built from Nand gates”（万物皆可Nand）

在逻辑代数中，一个非常重要的概念叫 “功能完备集”。意思是：只使用这一种运算，就能组合出所有其他的逻辑运算（And, Or, Not, Xor, 加法器, ALU, CPU...）

Nand 一个门就能“生”出所有门

1. **数学上**: Any Boolean function can be represented using an expression containing AND and NOT operations. 任何布尔函数都可以使用包含 AND（与）和 NOT（非）运算的表达式来表示。

证明: `(x OR Y) = NOT(NOT(x) AND NOT(y))`

2. **工程上**: Any Boolean function can be represented using an expression containing only NAND operations. 任何布尔函数都可以使用仅包含 NAND（与非）门运算的表达式来表示。

证明:

- `NOT(x) = (x NAND x)`
- `(x AND y) = NOT(x NAND y)`

**Nand** 的规则是：`out = NOT (a AND b)`，即 **有0出1，全1出0**。

```python
def nand_gate(a,b):
    return not (a and b)
```
